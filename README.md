# TimeTrackerApp

Нативное macOS-приложение для учета рабочего времени.

## Release

На данный момент нету подписи разработчика, чтобы установить себе нужно установить x-code и запустить скрипт:
Собрать `.dmg` локально можно скриптом:

```bash
./scripts/build_release_dmg.sh
```

После успешной сборки файл появится по пути `BuildArtifacts/TimeTrack.dmg`.
